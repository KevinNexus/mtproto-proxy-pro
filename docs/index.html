使用方法

1 · 登录并验证

使用 Telegram 登录，并确认已加入资源公社官方频道。

2 · 选择代理

按国家、延迟和抗封锁状态筛选合适的代理。

3 · 一键连接

点击连接按钮，跳转到 Telegram 官方代理设置页面并确认启用。

使用提醒： 公共代理可能随时失效。请勿将未知代理视为绝对安全，也不要在不可信的服务上提交敏感信息。

常见问题

为什么需要登录 Telegram？

登录用于确认 Telegram 用户身份，系统还会检查你是否加入资源公社官方频道。

登录后为什么仍然看不到代理？

请确认已经加入 @CXSNS，并检查页面显示的验证提示。如果验证服务暂时不可用，请稍后重试。

代理为什么可能无法连接？

公共代理可能过载、被封锁或停止服务。可以尝试其他节点，并留意延迟和检测状态。

如何退出登录？

验证成功后，可以使用登录区域中的退出登录按钮清除当前会话。
